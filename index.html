本周护肤要点

🥇 已为你选好的产品方案 · 油皮 + 敏感肌 + 外油内干 + 干燥

不是"列一堆给你挑"，是按肤质类型 + 文献证据直接选定一套；任何刺痛 / 泛红 / 起皮 → 退回修复期。

📚 学术依据（为什么这套护肤）

  • VC（修丽可 CE Ferulic）：Pinnell et al. 2003《L-ascorbic acid percutaneous absorption》Dermatol Surg；15% L-AA + 1% VE + 阿魏酸的 Duke 配方为抗氧金标准。
  • 烟酰胺：Draelos et al. 2006 J Cosmet Sci 显示 2-5% 烟酰胺减少皮脂；Hakozaki et al. 2002 Br J Dermatol 显示提亮 + 抑黑色素转移。
  • 视黄醇（理肤泉 Retinol B3）：Mukherjee et al. 2006《Retinoids in the treatment of skin aging》Clin Interv Aging；外用维生素 A 衍生物为光老化金标准。
  • 神经酰胺（珂润 / CeraVe）：Pilgram et al. 2001 J Invest Dermatol；神经酰胺是健康角质层屏障的主要脂质成分；屏障受损者补充可显著改善 TEWL。
  • 透明质酸（修丽可 B5）：Papakonstantinou et al. 2012 Dermatoendocrinol；HA 多分子量组合可同时滋润表皮与刺激真皮。
  • 水杨酸（宝拉珍选 2% BHA）：Zander & Weisman 1992 Cutis；油溶性 BHA 渗透毛囊改善油性肌粉刺。
  • 杏仁酸（Wishtrend 5% PHA）：Taylor 2018 Dermatol Surg 显示 mandelic acid 对深肤色 / 敏感肌的 melasma 安全有效；分子量大 → 渗透浅 → 刺激小。
  • 防晒（ANESSA 敏感肌 / 理肤泉 UVMUNE 400）：AAD 2021 推荐 SPF≥30 PA+++ 每日；UVMUNE 400 含 Mexoryl 400，UVA 长波防护最佳。
  • 使用顺序：分子量小 → 大；水状 → 乳状 → 霜状 → 油状（消费者皮肤医学共识）。

三阶段原则

  • 修复期 W1-4：只加保湿，不刷酸、不上 VC、不上视黄醇。让屏障稳。
  • 建设期 W5-8：一次只加一个新成分（先 VC，再视黄醇，最后 BHA）。每周 2 次起步。
  • 巩固期 W9-12：维持 + 引入 1 次/周 的杏仁酸焕肤 + 严格防晒 SPF50。
  • 红线：刺痛 + 泛红 + 起皮 → 立即停所有酸 / VC / 视黄醇，回到修复期 1 周。经期前 3 天与经期不刷酸。

底层方法论（神经科学 / 金融学 / 学习语言学 / 运动 / 中医）

1. 神经科学 · 把习惯放在已存在的钩子上
  • 提示 → 行为 → 奖励。新任务都绑在旧动作上："刷牙 → 打开 VSCode 写 5 行 Python"。
  • 多巴胺峰值在期待，不在完成。傍晚回顾"小胜利清单"强化路径。
  • 间隔重复：用 Anki 牌组，节奏 1d / 3d / 7d / 21d（本网页内置）。
  • 睡眠是离线编译器。23:00 前入睡；午间 20min NSDR 提升当日留存约 20%。
2. 学习语言学 · 先读、再改、最后写
  • 先读优秀代码（pandas 官方 cookbook、quantopian 旧策略），再修改，最后从零写。
  • 每天写 100 字"昨日所学讲给奶奶听"（费曼）→ 进"日志-情绪"备注。
3. 金融学 · 先理解风险，再追求收益
  • 顺序：市场结构 → 资产定价 → 因子 → 时间序列 → 组合优化 → 风控。
  • 原则：没有 walk-forward 回测的策略不上实盘；夏普 < 1 不上；先样本外。
  • 把"减肥"当量化项目：缺口=策略，体重=PnL，嗳气=回撤，每周复盘=回测。
4. 运动 + 中医（脾胃虚弱 + 经期友好）
  • 避免空腹高强度；优先 力量（保肌=保代谢）+ 餐后慢走（降血糖、助消化）。
  • 每周 3 力量 + 4 快走 + 1 瑜伽（脾经/胃经拉伸）；黄体期降量 15%。
  • 嗳气：八段锦"调理脾胃须单举"每日 1 组；按 足三里 3 分钟。
  • 不饱腹立刻坐着学习 → 形成"吃 → 走 → 学"节律。
5. 节奏 · 双轨深度块
  • 每天 2 个 90 分钟深度块（早 DS、晚 量化）+ 3 个番茄。
  • 双轨：本周 DS 主题 + 金融主题互为应用场景（pandas 做因子、sklearn 选股）。
6. 风险红线
  • 单周 -1.5kg 或 心率/睡眠下滑 → 加 200 kcal。
  • 嗳气强度 ≥ 2 连续 3 天 / 反酸 / 胃痛 → 退回温粥蒸食 3 天，必要时就医。
  • 学习卡顿 ≥ 2 天 → 砍半保链。链条 > 完成度。
★ 0. 客户量身：脂肪分布 + AI 加速 + 零基础友好
  • 客户脂肪分布：臀腿（gluteofemoral，下半身皮下）+ 腰腹（abdominal，皮下 + 少量内脏）
  • 科学事实：
    • 腰腹脂肪 先掉，对赤字、HIIT、睡眠最响应（Després 2012 NEJM；Vissers 2013 PLoS One meta；Wewege 2017 Obes Rev）
    • 臀腿脂肪 最难掉，受雌激素 + α2 肾上腺受体保护（Manolopoulos 2010 Int J Obes；Wajchenberg 2000 Endocr Rev）
  • 战略：
    • 第 1 个月：腰腹优先 — 睡眠 ≥7h、HIIT 18-25min/次、压力管理（Spiegel 2004 Lancet；Epel 2000）；预期 3-4 周看腰围 -3-5cm
    • 第 2 个月：下肢力量塑形（深蹲 / 臀桥 / 硬拉 / 弓步）— 不是为了点状减脂（不可能），而是建肌改善线条（Schoenfeld 2018 J Strength Cond Res）
    • 第 3 个月：维持赤字 + 高蛋白保肌；最后掉的是臀腿，需耐心（Helms 2014 J ISSN）
  • 不要做（迷思清单）：
    • 仰卧起坐 100 个减肚子（点状减脂不存在 — Vispute 2011 J Strength Cond Res）
    • 绑保鲜膜 / 震动腰带 / 暴汗服（出的是水分不是脂肪）
    • 不吃晚饭（破坏代谢与睡眠；ACSM 2009）
    • 跑步 1 小时但完全不力量（保肌靠抗阻；Stiegler 2006）
  • AI 加速学习方法论（Mollick 2024 Co-Intelligence；Wharton 2023）：
    • 初学者 + AI 助教 = 学习速度 ↑25-50%（OpenAI 2024 教育报告 / Khan Academy Khanmigo 试点）
    • 金融 / DS 零基础但学习能力强 → 善用 AI = 12 周可掌握以往 6 个月内容
    • 红线：AI 用来 解释、检查、生成 Anki 卡，不要让它 替你写整段作业。要做船长不做副驾驶
    • 每天读完 AI 解释后，用费曼技巧讲一遍给自己听（or 录音 → 让 AI 检查理解漏洞）
7. 护肤底层
  • 顺序：屏障修复 > 防晒 > 抗氧（VC）> 抗老（视黄醇）> 焕肤（水杨酸/果酸）。
  • 新成分一次加一个；任何刺痛/泛红/起皮 → 退回修复期。
  • 身体补水：洗澡 ≤ 38°C、3min 内身体乳、每日饮水 1.6L+。
  • 美白靠"减少黑色素生成 + 加速代谢"：VC（早）+ 视黄醇/果酸（晚）+ 严格防晒。
