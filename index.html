每日通用守则（脾胃友好 v2）

  • 晨起 200ml 温水 + 5min 腹式呼吸；空腹不冰饮、不浓茶；餐前 15min 喝 150ml 温柠檬水或淡陈皮水。
  • 三餐七分饱，每口咀嚼 25–30 次；餐后慢走 15min 再坐下学习；蛋白每日 ≥ 65g（鱼优先）。
  • 避免：生冷 / 沙拉 / 冰奶茶 / 糯米 / 油炸 / 碳酸 / 豆浆+鸡蛋同食。
  • 友好食材：小米、山药、南瓜、红枣、生姜、陈皮、茯苓、炒薏米、鲈鱼/龙利鱼/鳕鱼、蒸蛋。
  • 嗳气频繁：按压 内关（腕横纹上 2 寸）+ 中脘（脐上 4 寸）+ 足三里（外膝眼下 3 寸）各 1 分钟；每日 14:00 与 21:00 主动按一次。
  • 23:00 前入睡；睡前 90min 不再进食、不刷购物 / 信息流。

本周护肤要点

90 天护肤计划（三阶段）

修复期 W1–4 · 屏障+温和
  • 洁面：氨基酸洁面（早 1 / 晚 1，水温 32–34°C）
  • 保湿：化妆水 → 烟酰胺 2% 精华 → 神经酰胺乳液
  • T 区控油：水杨酸 0.5% 单点（隔日，不全脸）
  • 防晒：每日 SPF30 PA+++（出门前 15min）
  • 身体补水：淋浴水温 ≤ 38°C；3 分钟内全身身体乳；饮水 1.6L/天
  • 禁忌：刷酸 + 视黄醇 + 维 C 同周叠加
建设期 W5–8 · 加入活性成分
  • 早：3-O-乙基抗坏血酸（VC 衍生物）5% → 烟酰胺 → SPF50
  • 晚：0.1% 视黄醇 / 视黄酯 每周 2→3 次（避开经期前 3 天 + 经期）
  • T 区水杨酸：每日单点
  • 每周 1 次黏土面膜（仅 T 区）
  • 身体：每周 1 次身体磨砂（不在月经期）；尿素 5% 身体乳
  • 内调：每日 1 个猕猴桃或 200ml 鲜榨橙汁
巩固期 W9–12 · 提亮 + 长期化
  • 早：VC + 烟酰胺 + SPF50（户外加补涂）
  • 晚：视黄醇 3–4 次/周
  • 每周 1 次杏仁酸 8% 化学焕肤（晚间，次日严格防晒）
  • 身体磨砂每周 2 次；尿素 10% 身体乳
  • 内调：维生素 D 1000IU；保持每日 ≥ 1 拳深色蔬菜 + 1 拳水果
  • 固化习惯：洗澡 ≤ 38°C / 不揉搓 / 出门必防晒

原则：温和 > 猛料；新成分一次只加一种；任何刺痛 / 泛红 / 起皮 → 立即回到修复期 1 周。

底层方法论（神经科学 / 金融学 / 学习语言学 / 运动 / 中医）

1. 神经科学 · 把习惯放在已存在的钩子上
  • 提示 → 行为 → 奖励。新任务都绑在旧动作上："刷牙 → 打开 VSCode 写 5 行 Python"。
  • 多巴胺峰值在期待，不在完成。傍晚回顾"小胜利清单"强化路径。
  • 间隔重复：用 Anki 牌组，节奏 1d / 3d / 7d / 21d（本网页内置）。
  • 睡眠是离线编译器。23:00 前入睡；午间 20min NSDR 提升当日留存约 20%。
2. 学习语言学 · 先读、再改、最后写
  • 先读优秀代码（pandas 官方 cookbook、quantopian 旧策略），再修改，最后从零写。
  • 每天写 100 字"昨日所学讲给奶奶听"（费曼）→ 进"日志-情绪"备注。
3. 金融学 · 先理解风险，再追求收益
  • 顺序：市场结构 → 资产定价 → 因子 → 时间序列 → 组合优化 → 风控。
  • 原则：没有 walk-forward 回测的策略不上实盘；夏普 < 1 不上；先样本外。
  • 把"减肥"当量化项目：缺口=策略，体重=PnL，嗳气=回撤，每周复盘=回测。
4. 运动 + 中医（脾胃虚弱 + 经期友好）
  • 避免空腹高强度；优先 力量（保肌=保代谢）+ 餐后慢走（降血糖、助消化）。
  • 每周 3 力量 + 4 快走 + 1 瑜伽（脾经/胃经拉伸）；黄体期降量 15%。
  • 嗳气：八段锦"调理脾胃须单举"每日 1 组；按 足三里 3 分钟。
  • 不饱腹立刻坐着学习 → 形成"吃 → 走 → 学"节律。
5. 节奏 · 双轨深度块
  • 每天 2 个 90 分钟深度块（早 DS、晚 量化）+ 3 个番茄。
  • 双轨：本周 DS 主题 + 金融主题互为应用场景（pandas 做因子、sklearn 选股）。
6. 风险红线
  • 单周 -1.5kg 或 心率/睡眠下滑 → 加 200 kcal。
  • 嗳气强度 ≥ 2 连续 3 天 / 反酸 / 胃痛 → 退回温粥蒸食 3 天，必要时就医。
  • 学习卡顿 ≥ 2 天 → 砍半保链。链条 > 完成度。
7. 护肤底层
  • 顺序：屏障修复 > 防晒 > 抗氧（VC）> 抗老（视黄醇）> 焕肤（水杨酸/果酸）。
  • 新成分一次加一个；任何刺痛/泛红/起皮 → 退回修复期。
  • 身体补水：洗澡 ≤ 38°C、3min 内身体乳、每日饮水 1.6L+。
  • 美白靠"减少黑色素生成 + 加速代谢"：VC（早）+ 视黄醇/果酸（晚）+ 严格防晒。
