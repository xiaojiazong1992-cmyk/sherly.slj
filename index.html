每日通用守则（脾胃友好版）

  • 晨起 200ml 温水 + 5min 腹式呼吸；空腹不冰饮、不浓茶。
  • 三餐七分饱，每口咀嚼 25–30 次；餐后慢走 15min 再坐下学习。
  • 避免：生冷/沙拉/冰奶茶/糯米/油炸/碳酸/豆浆+鸡蛋同食。
  • 友好食材：小米、山药、南瓜、红枣、生姜、陈皮、鲈鱼、蒸蛋、小米粥配蔬菜。
  • 嗳气频繁时按压 内关（腕横纹上 2 寸）+ 中脘（脐上 4 寸）各 1 分钟。
  • 23:00 前入睡；睡前 90min 不再进食、不刷盘中商品。

初始数据 / 目标

  • 性别：女 · 年龄：22 · 身高：153cm
  • 起点体重：56.3kg · 体脂量：17.7kg（约 31.4%，偏高）
  • 去脂体重：38.6kg · 肌肉量：35.9kg · 骨质：2.7kg
  • BMR ≈ 1248 kcal；轻度活动 TDEE ≈ 1500–1700 kcal
  • 能量缺口：约 500–650 kcal/天，每周减 0.6–0.8kg（健康可持续）
  • 蛋白质摄入：≥ 65g/天（保护肌肉、防止反弹）
  • 3 个月目标：体重 46–47kg、体脂率 ≤ 22%、腰围 -8cm

注：减重并非线性。第 1–10 天多为水分回落（−1.5kg 内属正常），真正脂肪下降发生在第 3 周后。脾胃虚者优先稳定消化，再逐步加大缺口。

底层方法论（来自神经科学 / 金融学 / 语言学 / 运动学）

1. 神经科学：把习惯放在已存在的钩子上
  • 提示 → 行为 → 奖励（Habit Loop）。每个新任务都绑定一个旧动作：例如"刷完牙 → 立刻打开 VSCode 写 5 行 Python"。
  • 多巴胺峰值在期待而非完成。每天用一份"小胜利清单"在傍晚回顾，强化路径。
  • 间隔重复（Spaced Repetition）：DS/量化新概念用 Anki，复习节奏 1d / 3d / 7d / 21d。
  • 睡眠是学习的离线编译器。23:00 前入睡，午间 20 分钟 NSDR/小睡可提升当日学习留存约 20%。
2. 学习语言学：先读、再改、最后写
  • 学 Python/SQL/策略代码不是从空白开始。先大量读优秀代码（pandas 官方示例、quantopian 旧策略），再修改，最后从零写。
  • 每天产出一段 "昨日学到的，用一句话讲给奶奶听"（费曼技巧），写到打卡表。
3. 金融学：先理解风险，再追求收益
  • 学习顺序：金融市场结构 → 资产定价（CAPM/Fama-French）→ 因子模型 → 时间序列 → 组合优化 → 实盘风控。
  • 原则：不要在没有回测的情况下相信任何策略；夏普 < 1 的策略不要上实盘；永远先做样本外测试。
  • 把"减肥"也当作量化项目：能量缺口=策略，体重=PnL，便秘/嗳气=回撤，每周复盘=回测。
4. 运动 & 中医（脾胃虚弱定制）
  • 避免空腹高强度有氧；优先 抗阻训练（保留肌肉=保留代谢）+ 餐后快走（降餐后血糖、助消化）。
  • 每周 3 次力量（自重+小哑铃 30min）+ 4 次快走（每次 6000–8000 步）+ 1 次低强度瑜伽（脾经/胃经拉伸）。
  • 嗳气/胀气：八段锦"调理脾胃须单举"每日 1 组；按压足三里（外膝眼下 3 寸）3 分钟。
  • 不在饱腹后立刻坐着学习。形成"吃 → 走 → 学"节律。
5. 节奏：番茄 + 深工作 + 双轨学习
  • 每天 2 个 90 分钟深度块（早上 DS、晚上 量化）+ 3 个番茄复习/编码块。
  • "双轨"学习：当周同时推进一个 DS 主题 + 一个金融主题，互相成为彼此的应用场景（用 pandas 做因子分析、用 sklearn 做选股）。
6. 风险与红线
  • 体重单周下降 > 1.5kg 或心率/睡眠明显下滑 → 把日热量上调 150–200 kcal。
  • 嗳气连续 3 天加重、出现胃痛/反酸 → 暂停高强度训练，回到温粥+蒸食 3 天，必要时就医。
  • 学习卡顿连续 2 天 → 把当日任务砍半，保住打卡链条比完成度更重要。
