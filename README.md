# 90 天蜕变计划 v2 · 数据科学 × 金融量化 × 减脂 × 护肤

为 153cm / 56.3kg / 22 岁、脾胃虚弱（易嗳气）的女性学习者量身定制的 3 个月计划：
从小白到能独立做研究的水平，同时减重约 10kg、调脾胃、改善 T 区出油与全身补水。

## 怎么用

1. 双击 `index.html`，在任意现代浏览器中打开（**100% 离线、零依赖、零 CDN**）。
2. 默认以"今天"为第 1 天；可在「数据」页修改启动日。
3. 每天勾选 12 项任务；当日 ≥80% 计入连胜，热力图变绿。
4. 「日志」页：饮食（自带 ~70 种食物的热量/蛋白/中医寒温属性）+ 饮水 + 睡眠 + 嗳气 + 情绪 + 经期。
5. 「体测 & 趋势」页：原生 SVG 趋势图（含 7 日均线 + 起点线 + 目标线），月经期点用空心标记不参与均线。
6. 「护肤」页：90 天三阶段方案（修复期 / 建设期 / 巩固期）+ 日步骤打卡 + T 区出油/水分/亮度评分。
7. 「Anki 卡片」页：内置 30+ 张数据科学/量化/统计/中医基础卡，支持 1d/3d/7d/21d 间隔重复。
8. 「复盘」页：W4 / W8 / W12 结构化月度复盘（3 进步 / 3 卡点 / 3 改善 / 下月最重要的 1 件事 / 心情）。
9. 换设备：用「导出 JSON」备份 → 在新设备「导入 JSON」恢复；体测亦可导出 CSV。

## 自动化亮点

- **经期模块**：黄体期训练强度 ×0.85；月经期 HIIT/慢跑自动改瑜伽 + 八段锦；体重不计入均线。
- **嗳气警报**：近 3 日累计 ≥ 6 → 顶部红条提示回到温粥蒸食、+200 kcal/天暂缓缺口。
- **减重过快警报**：近 7 日体重下降 > 1.5kg → 顶部黄条提示加 200 kcal 保肌。
- **饮食提示**：每日寒凉 ≥ 2 项、蛋白 < 65g、kcal 超额 → 自动 pill 标签。

## 设计原则（详见网页「原则」页）

- **神经科学**：习惯钩子、间隔重复（内置 Anki）、睡眠是离线编译器
- **学习语言学**：先读，再改，最后写；每天费曼输出 100 字
- **金融学**：先理解风险再追求收益；不上无 walk-forward 回测的策略
- **运动 + 中医**：避免空腹高强度；力量+餐后慢走；八段锦 / 内关 / 中脘 / 足三里
- **护肤**：温和长期 > 短期猛料；新成分一次只加一种；任何刺痛回到修复期

## 安全红线

- 单周减 > 1.5kg、心率/睡眠下滑 → 加 200 kcal/天
- 嗳气强度 ≥ 2 连续 3 天 / 反酸 / 胃痛 → 退回温粥蒸食 3 天，必要时就医
- 学习卡顿 ≥ 2 天 → 砍半保住打卡链；**链条比完成度更重要**
- 任何护肤刺痛 / 泛红 / 起皮 → 立即回到修复期 1 周
