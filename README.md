# 90 天蜕变计划 · 数据科学 × 金融量化 × 健康减脂

为 153cm / 56.3kg / 22 岁、脾胃虚弱（易嗳气）的学习者量身定制的 3 个月计划：
从小白到能独立做研究的水平，同时减重约 10kg。

## 怎么用

1. 直接双击 `index.html`，在任意现代浏览器打开（不需要后端、不联网）。
2. 默认以"今天"为第 1 天；可在「数据导入导出」页修改启动日。
3. 每天勾选完成项；当日 ≥80% 计入连胜，热力图变绿。
4. 在「体重 & 体型」页记录晨起体重 / 腰围 / 体脂；进度条会自动更新。
5. 换设备：用「导出 JSON」备份 → 在新设备「导入 JSON」恢复。

## 设计原则（详见网页「原则与底层逻辑」页）

- **神经科学**：习惯钩子、间隔重复（Anki）、睡眠是离线编译器
- **学习语言学**：先读，再改，最后写；费曼输出
- **金融学**：先理解风险再追求收益；不上无回测的策略
- **运动 + 中医**：避免空腹高强度；力量 + 餐后慢走；八段锦 / 内关 / 足三里
- **节奏**：每天 2 个 90min 深度块 + 双轨学习（DS + 量化互为应用场景）

## 安全红线

- 单周减重 > 1.5kg、心率/睡眠下滑 → 加 150–200 kcal
- 嗳气加重 / 反酸 / 胃痛 ≥ 3 天 → 暂停高强度，回到温粥蒸食 3 天，必要时就医
- 学习卡顿 ≥ 2 天 → 砍半保住打卡链；**链条比完成度更重要**
